# PhySGA Project Page

Project page for **PhySGA: A Physics-Space Grounded Agentic Framework for Generalizable and Interactive 3D Composition**.

The page follows the structure of the [SimRecon project page](https://xiac20.github.io/SimRecon/) and the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template).

## Local preview

From the repository root, run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
